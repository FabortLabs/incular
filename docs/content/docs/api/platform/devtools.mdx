```toml
[dependencies]
incular = { version = "0.1", features = ["devtools"] }
```

Enables `incular-devtools` (bridge) + `incular-devtools-protocol` (versioned
messages). The standalone DevTools application under `tools/` is unpublished.

| Piece | Role |
| --- | --- |
| `incular-devtools` | Diagnostics transport bridge (feature-gated) |
| `incular-devtools-protocol` | Versioned messages shared with tooling |
| `tools/` app | Standalone desktop inspector (unpublished) |

## Devtools-only signal helpers

`signal.devtools("counter")` (named, `T: Debug`) and
`signal.devtools_editable()` (editable for `bool`/`i64`/`u64`/`f64`/`String`)
exist only with the feature enabled, so they stay out of runnable programs —
gate any use behind the `devtools` feature like the `Cargo.toml` above.

## Privacy

DevTools is an authenticated **local** diagnostic interface, not a network
service. Treat discovery credentials, text, screenshots, and crash dumps as
sensitive. See diagnostics privacy notes in the repository.

Related: [`Testing`](/docs/api/platform/testing).
