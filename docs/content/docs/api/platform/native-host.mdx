Bridges for embedders hosting Incular views natively.

```rust
use incular::prelude::*;

fn main() {
    let controller = ViewAnchorController::new();
    println!("attached: {}", controller.data().attached);
    controller.detach();
    println!("handles: {}", controller.active_handle().is_none());
}
```

`AuxiliaryViewRequest { view_id, child, metrics, environment, anchor, title }`,
`AuxiliaryViewHandle { view_id, token }`, [`AuxiliaryViewError`](/docs/api/platform/native-host): `Unsupported` /
`Rejected` / `Invalid`; [`NoopAuxiliaryViewHost`](/docs/api/platform/native-host) always declines.
[`ApplicationBootstrapOptions`](/docs/api/application/widgets-app) / [`ApplicationBootstrapSpec`](/docs/api/application/widgets-app) /
`ApplicationBootstrapHost::create_application` adapt roots to runtimes.
`WindowChromeSink::set_title` / `set_application_color`
([`NoopWindowChromeSink`](/docs/api/platform/native-host) declines). `WindowDragRegion::new(child)` starts
native moves; `WindowResizeRegion::new(direction, child)` starts resizes —
interactive descendants take precedence in both.

Related: [`View`](/docs/api/application/view),
[`Title`](/docs/api/environment/title).
