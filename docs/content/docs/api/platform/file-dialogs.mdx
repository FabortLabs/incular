---

`FileDialogRequest { kind, options }` is fully validated before dispatch;
cancellation arrives as an outcome, not an error.

```rust
use incular::prelude::*;

fn main() {
    let filter =
        FileDialogFilter::extensions("images", "Images", ["png", "jpg"])
            .expect("filter");
    println!("filter: {}", filter.id().as_str());
    let ext = FileExtension::new("png").expect("extension");
    println!("ext: {}", ext.as_str());
    let content = FileContentType::new("image/png").expect("content type");
    println!("kind: {}", content.kind() == FileContentTypeKind::Mime);
}
```

[`FileDialogFilterId`](/docs/api/platform/file-dialogs) is the stable semantic identity (labels are
presentation-only). [`FileDialogOption`](/docs/api/platform/file-dialogs): `ExtensionFilters` /
`MimeTypeFilters` / `TypeIdentifierFilters` / `SuggestedFileName` /
`SuggestedDirectory` / `ParentWindow` (backend-support varies).
[`FileDialogValidationError`](/docs/api/platform/file-dialogs): bad ids/labels/extensions/content-types, empty or
duplicate filters, inapplicable options. [`FileDialogError`](/docs/api/platform/file-dialogs): invalid request,
closed parent, stopped app, unsupported op/option, bad result, backend message.
[`DocumentActivation`](/docs/api/application/application) (`from_paths`, `documents()`) and [`DocumentDescriptor`](/docs/api/application/application)
(path preserved exactly) model open-document intents.
[`FileContentTypeKind`](/docs/api/platform/file-dialogs): `Mime` / `TypeIdentifier` — the identifier family.

Related: [`Application`](/docs/api/application/application).
