```rust
use incular::prelude::*;

fn main() {
    println!("shortcut id: {}", GlobalShortcutId::new(1).get());
    println!("tray: {}", TrayItemId::from_parts(0, 1).index());
    let progress = TaskbarProgress::normal(0.5).expect("progress");
    println!("fraction: {:?}", progress.fraction());
    let _dock = TaskbarDockState::for_window(WindowId::from_parts(0, 1))
        .progress(progress)
        .badge(ApplicationBadge::Count(3));
}
```

[`TaskbarProgress`](/docs/api/platform/shortcuts-tray): `None` / `Indeterminate` / `Normal(f)` / `Paused(f)` /
`Error(f)` (`fraction()` reads back; non-finite/out-of-range rejected:
[`TaskbarProgressError`](/docs/api/platform/shortcuts-tray)). [`ApplicationBadge`](/docs/api/platform/shortcuts-tray): `None` (default) / `Count(u64)` / `Text(String)`.
Runtime handles ([`GlobalShortcutRegistration`](/docs/api/platform/shortcuts-tray), [`NotificationHandle`](/docs/api/platform/shortcuts-tray),
[`TrayItemHandle`](/docs/api/platform/shortcuts-tray)) live in `incular-runtime`; platform holds the stable ids
([`GlobalShortcutId`](/docs/api/platform/shortcuts-tray), [`NotificationId`](/docs/api/platform/shortcuts-tray) /
[`NotificationActionId`](/docs/api/platform/shortcuts-tray), [`TrayItemId`](/docs/api/platform/shortcuts-tray)).
[`GlobalShortcutUnregistrationRequest`](/docs/api/platform/shortcuts-tray) awaits unregistration like its
registration counterpart.

Related: [`Application`](/docs/api/application/application).
