Every example lives in its own directory with `main.rs`, a simulation
scenario, and an integration test. Run any of them with:

```text
cargo run -p incular --example <name>
```

Only `hello` ships inside the registry archive; the rest need a checkout.
Each gallery doubles as executable documentation for its reference pages.
