---
title: Opacity
description: Isolated compositor opacity groups and fade transitions.
icon: Ghost
---

Isolated compositor group — never affects hit-testing or semantics. Alpha
normalizes to `0..=1`.

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Column::builder()
                    .main_axis_size(MainAxisSize::Min)
                    .spacing(8.0)
                    .children(Vec::<Widget>::from([
                        Opacity::new(1.0, Text::new("Solid")).into(),
                        Opacity::new(0.5, Text::new("Half")).into(),
                        Opacity::new(0.0, Text::new("Gone")).into(),
                    ]))
                    .build(),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

Controller ticks update only the retained compositor property — no rebuild,
relayout, or repaint once warm.

| Widget | Purpose |
| --- | --- |
| [`Opacity`](/docs/api/painting/opacity) | Static or controlled group alpha |
| [`FadeTransition`](/docs/api/painting/opacity) | Controller-driven fade |
| [`SlideTransition`](/docs/api/painting/opacity) | Controller-driven slide |
| [`Transition`](/docs/api/painting/opacity) | Combined opacity + translation primitive |

Related: [`Transform`](/docs/api/painting/transform-widget),
[`AnimationController`](/docs/api/painting/animation).
