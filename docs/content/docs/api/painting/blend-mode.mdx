```rust
use incular::prelude::*;

fn main() {
    let modes = [
        BlendMode::SrcOver,
        BlendMode::Src,
        BlendMode::Multiply,
        BlendMode::Screen,
        BlendMode::Difference,
    ];
    println!("src_over reads dst: {}", BlendMode::SrcOver.requires_destination_read());
    println!("modes: {}", modes.len());
    println!("code: {}", BlendMode::SrcOver.code());
}
```

| Family | Variants |
| --- | --- |
| Porter-Duff | `SrcOver` (default), `Src`, `DstOver`, `SrcIn`, `DstIn`, `SrcOut`, `DstOut`, `SrcAtop`, `DstAtop`, `Xor`, `Plus` |
| Blend | `Multiply`, `Screen`, [`Overlay`](/docs/api/navigation/routes), `Darken`, `Lighten` |
| Dodge/Burn | `ColorDodge`, `ColorBurn`, `HardLight`, `SoftLight` |
| Difference | `Difference`, `Exclusion`, `Modulate` |
