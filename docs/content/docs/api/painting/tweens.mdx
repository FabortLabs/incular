---
title: Tweens
description: Typed interpolation values and weighted sequences.
icon: TrendingUp
---

```rust
let t = TweenValue::new(0.0f32, 100.0);
let t = TweenValue::curved(0.0, 100.0, Curve::EaseOut);
t.curve(Curve::EaseIn)
t.evaluate(0.5) // curve.apply then interpolate
t.lerp(0.5)     // no curve, clamped t
t.reversed()
t.then(next)    // TweenSequence

TweenSequence::new()
    .push(TweenValue::new(0.0, 50.0), 1.0)
    .push(TweenValue::new(50.0, 100.0), 2.0)
seq.evaluate(0.75) // Option<T>; None if empty
seq.is_empty() / seq.len() / seq.segments()
```

[`Tween`](/docs/api/painting/tweens) is implemented for `f32`, `f64`, `i32`, `u32`,
[`Offset`](/docs/api/values/offset), [`Size`](/docs/api/values/size),
[`Color`](/docs/api/values/color). Non-finite or non-positive segment weights
are ignored.

| Type | Purpose |
| --- | --- |
| `TweenValue<T>` | Begin/end pair with optional curve |
| `TweenSegment<T>` | Value plus sequence weight |
| `TweenSequence<T>` | Weighted multi-segment interpolation |
| `Animation<T>` | Controller-bound evaluated value |
| `ImplicitAnimation<T>` | Retargets from the current value |

```rust
Animation::new(controller, tween)
Animation::from_to(controller, 0.0, 100.0)
anim.value() / anim.value_at(t) / anim.forward(now) / anim.tick(now) / anim.map(f)
ImplicitAnimation::new(controller, begin, end) // retargets from current value
implicit.set_target(100.0) / implicit.set_curve(Curve::EaseOut)
```
