title: DecoratedBoxTransition
description: Animated decoration transition for decorated boxes.
icon: PaintBucket
---

[`DecoratedBoxTransition`](/docs/api/transitions/decorated-box-transition) transitions a [`DecoratedBox`](/docs/api/layout-widgets/decorated-box)
decoration explicitly (currently a child passthrough as the animation plumbing
lands).

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        DecoratedBoxTransition::new(Text::new("Hi")).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

Related: [`DecoratedBox`](/docs/api/layout-widgets/decorated-box).
