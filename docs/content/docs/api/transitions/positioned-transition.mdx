[`PositionedTransition`](/docs/api/transitions/positioned-transition) animates a [`Positioned`](/docs/api/layout-widgets/positioned)
child's edges (all default `None`, like [`Positioned`](/docs/api/layout-widgets/positioned)).

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Stack::builder()
                .children(Vec::<Widget>::from([PositionedTransition::new(Text::new("Hi"))
                        .left(8.0)
                        .top(8.0)
                        .right(8.0)
                        .bottom(8.0).into()]))
                .build().into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

Setters: `left`, `top`, `right`, `bottom` (explicit impl setters); `width` and
`height` exist as builder fields via `TypedBuilder`.

Related: [`Positioned`](/docs/api/layout-widgets/positioned),
[`RelativePositionedTransition`](/docs/api/transitions/relative-positioned-transition).
