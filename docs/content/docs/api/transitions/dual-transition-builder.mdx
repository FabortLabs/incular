title: DualTransitionBuilder
description: Dual forward and reverse transition composition.
icon: ArrowLeftRight
---

[`DualTransitionBuilder`](/docs/api/transitions/dual-transition-builder) composes separate forward and reverse transitions
around its child (currently a child passthrough as the composition lands).

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        DualTransitionBuilder::new(Text::new("Hi")).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```
