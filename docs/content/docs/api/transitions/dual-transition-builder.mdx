[`DualTransitionBuilder`](/docs/api/transitions/dual-transition-builder) composes separate forward and reverse transitions
around its child (currently a child passthrough as the composition lands).

```rust
DualTransitionBuilder::new(child)
```

Related: [`AnimationController`](/docs/api/painting/animation).
