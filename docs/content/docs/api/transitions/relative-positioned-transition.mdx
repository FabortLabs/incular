[`RelativePositionedTransition`](/docs/api/transitions/relative-positioned-transition) animates a relative positioned rect around its
child (currently a [`Positioned`](/docs/api/layout-widgets/positioned) passthrough as the animation plumbing lands).

```rust
RelativePositionedTransition::new(child)
```

Related: [`PositionedTransition`](/docs/api/transitions/positioned-transition),
[`Positioned`](/docs/api/layout-widgets/positioned).
