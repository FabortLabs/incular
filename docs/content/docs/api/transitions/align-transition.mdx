---
title: AlignTransition
description: Animated child alignment with size factors.
icon: Crosshair
---

[`AlignTransition`](/docs/api/transitions/align-transition) transitions its child's alignment, mirroring
[`Align`](/docs/api/layout-widgets/align) plus animation.

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        AlignTransition::new(Alignment::CENTER, Text::new("Hi"))
                .width_factor(1.0)
                .height_factor(1.0).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

Related: [`Align`](/docs/api/layout-widgets/align),
[`AnimationController`](/docs/api/painting/animation).
