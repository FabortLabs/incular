---
title: MatrixTransition
description: Animated arbitrary affine transform matrix.
icon: Rotate3d
---

`MatrixTransition { transform: CoreTransform, child: Widget }` transitions an
arbitrary affine matrix (both fields required).

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        MatrixTransition::new(
            AffineTransform::rotation(0.5),
            Text::new("Hi"),
        ).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```
