---

[`DefaultTextStyleTransition`](/docs/api/transitions/default-text-style-transition) is the explicit-animation counterpart to
[`DefaultTextStyle`](/docs/api/environment/default-text-style) (currently
forwards its child as the animation plumbing lands).

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        DefaultTextStyleTransition::new(Text::new("Hi")).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

Related: [`DefaultTextStyle`](/docs/api/environment/default-text-style).
