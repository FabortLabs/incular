[`SizeTransition`](/docs/api/transitions/size-transition) animates its own size while clipping the child.
`size_factor` is clamped to `0..1`; default axis `Vertical`.

```rust
SizeTransition::new(0.5, child)
    .axis(Axis::Horizontal)
    .axis_alignment(0.0)
```
