Arena-free raw pointer callbacks (no gesture disambiguation).

| Widget | Purpose |
| --- | --- |
| [`Listener`](/docs/api/input/raw-input) | Raw down/move/up/hover/cancel/signal callbacks |
| [`RawGestureDetector`](/docs/api/input/raw-input) | Custom recognizer factories with hit behavior |
| [`MouseRegion`](/docs/api/input/raw-input) | Enter/exit/hover with cursor and opacity |
| [`TapRegion`](/docs/api/input/raw-input) | Inside/outside tap routing with groups |
| [`TapRegionSurface`](/docs/api/input/raw-input) | Nearest tap-region registry |
| [`TextFieldTapRegion`](/docs/api/input/raw-input) | TapRegion defaulting to the text-field group |

## Listener

```rust
use incular::prelude::*;
use incular::widgets::HitTestBehavior;

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Listener::new(Text::new("Touch me"))
                    .on_pointer_down(|_| println!("down"))
                    .on_pointer_up(|_| println!("up"))
                    .on_pointer_hover(|_| println!("hover"))
                    .behavior(HitTestBehavior::Opaque),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

[`ListenerCallbacks`](/docs/api/input/raw-input) holds all six `Option<Rc<dyn Fn(RawPointerEvent)>>`
plus trackpad.

## RawGestureDetector

Custom recognizer factories plug in here — see the factory types below; the
runnable [`Listener`](/docs/api/input/raw-input) program above shows the
retained-detector shape in action.

Custom recognizers implement [`GestureRecognizer`](/docs/api/input/raw-input) (`observe`, `observe_raw`,
`dispatch`, `cancel`, `dispose`, `as_any_mut`) and are constructed via
[`GestureRecognizerFactory`](/docs/api/input/raw-input) (`create`, `initialize`, `type_id`) or
`GestureRecognizerFactoryWithHandlers::new(constructor, initializer)`
(`with_initializer` for `Default` types). Mismatched types raise
`GestureRecognizerFactoryError { expected, actual }`.

## MouseRegion

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                MouseRegion::new(Text::new("Hover me"))
                    .on_enter(|_| println!("enter"))
                    .on_exit(|_| println!("exit"))
                    .on_hover(|_| println!("hover")),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

Enter waits for the first positioned move before resolving hover; exit clears
the retained hover route exactly once.

## TapRegion

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                TapRegionSurface::new(
                    TapRegion::new(Text::new("Tap inside or out"))
                        .on_tap_inside(|_| println!("inside"))
                        .on_tap_outside(|_| println!("outside"))
                        .consume_outside_taps(false),
                ),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

[`TapRegionGroupId`](/docs/api/input/raw-input): `Named(String)` / `Numeric(u64)` / [`TextField`](/docs/api/design/text-inputs) (default),
with `From<&str>`, `From<String>`, `From<u64>`. [`TextFieldTapRegion`](/docs/api/input/raw-input) is the
same shape defaulting to the text-field group.
[`ListenerCallbacks`](/docs/api/input/raw-input) / [`MouseRegionCallbacks`](/docs/api/input/raw-input) / [`TapRegionCallbacks`](/docs/api/input/raw-input) bundle the
`Option<Rc<dyn Fn…>>` callback sets for bulk installation via `callbacks(…)`.

Related: [`GestureDetector`](/docs/api/input/gesture-detector),
[`Hit Testing`](/docs/api/input/hit-test).
