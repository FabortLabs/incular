## Focus

| Widget | Purpose |
| --- | --- |
| [`Focus`](/docs/api/input/focus) | Attach node, autofocus, and request policy to a subtree |
| [`FocusScope`](/docs/api/input/focus) | Scope with traversal policy (`WidgetOrder` / `ReadingOrder` / `Ordered`) |
| [`FocusTraversalGroup`](/docs/api/input/focus) | Override policy for a region (default `ReadingOrder`) |
| [`FocusTraversalOrder`](/docs/api/input/focus) | Explicit numeric order (`order`, non-finite clears) |
| [`ExcludeFocus`](/docs/api/input/focus) | Remove subtree from focus order |
| [`ExcludeFocusTraversal`](/docs/api/input/focus) | Remove subtree from traversal only |

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                FocusScope::new(
                    Column::builder()
                        .main_axis_size(MainAxisSize::Min)
                        .spacing(8.0)
                        .children(Vec::<Widget>::from([
                            Focus::new(Text::new("First")).autofocus(true).into(),
                            Focus::new(Text::new("Second")).into(),
                        ]))
                        .build(),
                )
                .autofocus(true),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

Without an explicit node but with `autofocus` or `can_request_focus = false`,
[`Focus`](/docs/api/input/focus) creates one internally. Fully default [`Focus`](/docs/api/input/focus) returns the child
unchanged.

## FocusScope

`autofocus`, `policy(FocusTraversalPolicyKind::WidgetOrder)`,
`reading_order()`, `widget_order()`, `ordered()` — exercised in the runnable
program above.

## Traversal and exclusion

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        FocusTraversalGroup::new(Text::new("Hi")).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

[`FocusTraversalPolicy`](/docs/api/input/focus) trait (`find_first/last_focus`, `next`, `previous`)
with [`WidgetOrderTraversalPolicy`](/docs/api/input/focus) / [`ReadingOrderTraversalPolicy`](/docs/api/input/focus) /
[`OrderedTraversalPolicy`](/docs/api/input/focus) (explicit numeric order) implementations.

[`FocusScopeNode`](/docs/api/input/focus), [`FocusNode`](/docs/api/input/focus), [`FocusManager`](/docs/api/input/focus), and traversal policies
(`Ordered`, `ReadingOrder`, `WidgetOrder`) live in `incular-gestures`.
`BuildContext::watch_focus_scope(&scope)` subscribes a build to scope changes.

Related: [`Keyboard`](/docs/api/input/keyboard),
[`GestureDetector`](/docs/api/input/gesture-detector).
