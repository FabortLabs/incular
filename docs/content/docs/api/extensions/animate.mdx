---
title: Effect chains
description: animate() chains fades, slides, scales and other effects, after flutter_animate.
icon: Sparkles
---

`AnimateExt::animate()` wraps a widget in an `Animate` that plays a chain of
effects when the widget is first built, in the style of `flutter_animate`.
Effects added together run together. `then()` starts the next effects after
everything so far has finished. Each effect takes the chain's current
`duration` (default 300 ms) and `curve`; `ms` and `curve` change them for the
effects added after the call.

```rust
use std::time::Duration;

use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Directionality::new(
            TextDirection::Ltr,
            Text::new("Welcome")
                .animate()
                .delay(Duration::from_millis(100))
                .fade_in()
                .slide_y(0.3)
                .then()
                .ms(200)
                .scale_in(0.9)
                .on_complete(|| println!("intro finished")),
        )
        .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

| Effect | Meaning |
| --- | --- |
| `fade_in`, `fade_out`, `fade(begin, end)` | Opacity |
| `slide_x(begin)`, `slide_y(begin)`, `slide(begin, end)` | Offset as a fraction of the child's size |
| `move_from(offset)` | Offset in logical pixels |
| `scale_in(begin)`, `scale(begin, end)` | Uniform scale about the center |
| `rotate_in(begin)`, `rotate(begin, end)` | Rotation in turns |
| `blur_in(sigma)` | Blur that clears to sharp |
| `shake()` | Sideways shake |
| `effect(kind)`, `effect_at(kind, delay, duration, curve)` | Custom `EffectKind` with chain or explicit timing |

More effects: `move_x` / `move_y`, `tint(color, amount)`, `saturate`,
`shadow`, `clip_reveal(RevealFrom::..)`, `shimmer()`, and `keys(prop, [..])`
for keyframes. `custom(|t, pose| ..)` sets any pose property from the
chain's progress. `build_each_frame(|t, child| ..)` rebuilds its child every
frame, for the rare effect a pose cannot express. `then_gap(d)` and
`then_overlap(d)` space the next effects, and `apply(f)` reuses a preset
chain.

The chain runs on the motion engine. Its frames touch only compositor layers,
so a running chain causes no rebuild, relayout or repaint. Only clip reveals
and `build_each_frame` do more.

`repeat(AnimateRepeat::Loop)` restarts the chain forever, and
`AnimateRepeat::PingPong` plays it forward and back. Loops pause while the
element is off screen and under reduced motion.

`play(..)` chooses when the chain runs:

- `Play::OnMount` is the default.
- `Play::InView(InView::new().once())` plays the chain as the element scrolls
  into view.
- `Play::When(cond)` plays it forward while a condition holds and backward
  when it stops.
- `.handle(&handle)` drives it from an `AnimationHandle`, which offers
  `play`, `reverse`, `seek`, `restart` and an awaitable `finished()`.

`progress(..)` drives the chain from a value instead of time:

- `0.4` or a `MotionValue`.
- A `Signal<f32>`.
- `Progress::scroll()` maps the nearest scroll offset; narrow it with
  `.range(..)`.
- `Progress::view(ViewRange::Entry)` follows the element's own pass through
  the viewport.

`target(progress)` still works and is the same as `progress(progress)`.
A parent's `.motion(|m| m.stagger(..))` staggers the chains of its children.
`frame(elapsed)` builds the chain at a fixed time, which is handy in tests.
