[`SensitiveContent`](/docs/api/environment/sensitive-content) marks a subtree for the capture-protection policy;
[`SensitiveContentHost`](/docs/api/environment/sensitive-content) resolves priority (`Sensitive` > `AutoSensitive` >
`NotSensitive`) snapshotted at the window boundary.

```rust
use incular::prelude::*;

fn main() {
    let sensitive = SensitiveContent::new(Text::new("Secret"));
    println!("sensitivity: {:?}", sensitive.sensitivity());
    let relaxed = SensitiveContent::with_sensitivity(
        ContentSensitivity::NotSensitive,
        Text::new("Public"),
    )
    .sensitive(false);
    println!("relaxed: {:?}", relaxed.sensitivity());
    let app = Application::new(|_cx| {
        SensitiveContent::new(Text::new("Secret")).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

[`SensitiveContentHost`](/docs/api/environment/sensitive-content): `new()` / `with_fallback(s)` / `register(s)` /
`unregister(s)` / `calculated_content_sensitivity()` /
`effective_content_sensitivity()` / `has_widgets()` / `count(s)`.

Related: [`WindowHandle`](/docs/api/application/window).
