Everything application-facing is reachable through the `incular` facade. Depend
on leaf crates only to bypass it.

For generated Rust signatures and item-level documentation, use
[docs.rs/incular](https://docs.rs/incular) after publication, or run
`cargo doc --workspace --all-features --no-deps --open` from a checkout.

## Features

| Feature | Purpose | Default |
| --- | --- | --- |
| `desktop` | Native runner + every WGPU backend | Yes |
| `desktop-host` | Native runner; pair with at least one backend below | Via `desktop` |
| `dx12`, `metal`, `vulkan`, `gl` | WGPU backends; each enables `desktop-host`, ignored where unavailable | Via `desktop` |
| `controls` | Incular controls and visual slots | Yes |
| `material` | Material presentation; enables `controls` | Yes |
| `devtools` | Diagnostics transport + instrumentation | No |
| `hot-reload` | Live code patching in debug builds under `dx serve --hot-patch` | No |

## Preludes

| Import | Contents |
| --- | --- |
| `incular::prelude` | Neutral types: widgets, layout, text, runtime, animation, navigation, rendering (+ platform services with `desktop`) |
| `incular::controls_prelude` | [`Button`](/docs/api/design/button), [`Checkbox`](/docs/api/design/selection), [`Switch`](/docs/api/design/selection), [`Input`](/docs/api/design/text-inputs), [`Card`](/docs/api/design/surfaces), [`ControlTheme`](/docs/api/design/theme), … |
| `incular::material_prelude` | [`MaterialApp`](/docs/api/design/material-app), [`Scaffold`](/docs/api/design/material-app), buttons, dialogs, [`ThemeData`](/docs/api/design/theme), … |

## Namespaces

- `incular::scroll` — [`ScrollController`](/docs/api/navigation/scroll-controller), [`ScrollPhysics`](/docs/api/painting/physics), [`ScrollMetrics`](/docs/api/navigation/scroll-controller), and notifications
- `incular::reactive` — [`Action`](/docs/api/state/action), [`Effect`](/docs/api/state/effect), and [`Memo`](/docs/api/state/memo), kept distinct from widget names
- `incular::testing` — [`Simulation`, `Screenshot`](/docs/api/platform/testing)
- Top-level mirrors: `animation`, `config`, `core`, `gestures`, `image`,
  `layout`, `navigation`, `rendering` (alias `painting`), `runtime`,
  `semantics`, `text`, `widgets`; `controls`/`material` and
  `platform`/`wgpu`/OS runners are feature-gated.
