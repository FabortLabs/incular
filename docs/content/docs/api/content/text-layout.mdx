---

[`TextLayout`](/docs/api/content/text-layout) is the measured result of shaping a [`TextSpan`](/docs/api/content/rich-text):
lines, metrics, font runs, and caret positions.

```rust
use incular::prelude::*;

fn main() {
    let _options = TextLayoutOptions::new(Some(300.0), TextAlign::Start);
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Text::new("Measured with options")
                    .max_lines(Some(3))
                    .overflow(TextOverflow::Ellipsis),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

Selection painting is line-by-line from cached Parley caret stops; both
[`EditableText`](/docs/api/content/editable-text) and
[`SelectableRegion`](/docs/api/content/selectable-region) consume it.

Related: [`RichText`](/docs/api/content/rich-text),
[`TextStyle`](/docs/api/content/text-style).
