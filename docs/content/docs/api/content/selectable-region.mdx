---
title: SelectableRegion
description: Pointer-based text selection area without a mutable buffer.
icon: TextCursor
---

[`SelectableRegion`](/docs/api/content/selectable-region) is the retained selection primitive: no mutable text
buffer, caret, or IME route. Material [`SelectableText`](/docs/api/design/material-inputs) and [`SelectionArea`](/docs/api/design/material-inputs)
descriptors wrap it.

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(SelectableRegion::new(Text::new(
                "Drag across this text to select it.",
            )))
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

Selection rectangles derive from cached Parley-backed layout (wrapped,
mixed-font, bidirectional); selection changes repaint highlights without
reshaping glyphs. Keep a `SelectionAreaController` when application code needs
the copied selection.

Related: [`EditableText`](/docs/api/content/editable-text),
[`Text`](/docs/api/content/text).
