Shaped during layout. `Text::new` uses the default style, `Start` alignment,
wrapping on, no line limit, [`Clip`](/docs/api/values/clip) overflow. Does not expand — wrap in
[`Expanded`](/docs/api/layout-widgets/expanded) to fill.

## Constructors and setters

Every setter running — copy, paste, and run:

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Column::builder()
                    .main_axis_size(MainAxisSize::Min)
                    .spacing(8.0)
                    .children(Vec::<Widget>::from([
                        Text::new("Hello").into(),
                        Text::new("Emphasis")
                                .style(
                                    TextStyle::new().bold().font_size(18.0),
                                ).into(),
                        Text::new("Red")
                                .color(Color::rgba(200, 30, 30, 255)).into(),
                        Text::new("Centered").align(TextAlign::Center).into(),
                        Text::new("No wrap").soft_wrap(false).into(),
                        Text::new("Two lines at most")
                                .max_lines(Some(2))
                                .overflow(TextOverflow::Ellipsis).into(),
                    ]))
                    .build(),
            )
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

Setters: `style(`[`TextStyle`](/docs/api/content/text-style)`)`,
`color(Color)`, `align(TextAlign)`, `soft_wrap(bool)`,
`max_lines(Option<usize>)`, `overflow(TextOverflow)`.

## TextAlign and TextOverflow

[`TextAlign`](/docs/api/content/text): `Start` (default) / [`Center`](/docs/api/layout-widgets/center) / `End` / `Justify`.
[`TextOverflow`](/docs/api/content/text): [`Clip`](/docs/api/values/clip) (default) / `Ellipsis` / `Visible` / `Fade`.

For multi-style runs see [`RichText & Spans`](/docs/api/content/rich-text);
for editing see [`EditableText`](/docs/api/content/editable-text).

Related: [`TextStyle`](/docs/api/content/text-style),
[`Fonts`](/docs/api/content/fonts).
