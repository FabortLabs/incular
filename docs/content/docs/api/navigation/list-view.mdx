---
title: ListView
description: Eager and builder lists with extents, direction, and cache options.
icon: List
---

```rust
ListView::new(children)
ListView::builder(1000, |i| Text::new(format!("{i}")))
ListView::separated(100, item_builder, separator_builder) // total = n*2-1
    .controller(c)
    .padding(p)
    .scroll_direction(Axis::Vertical)
    .reverse(false)
    .shrink_wrap(false)
    .cache_extent(256.0)
    .physics(p)
    .item_extent(56.0)                  // finite -> max(1); clears builder/prototype
    .prototype_item(proto)
    .item_extent_builder(|i| 40.0)
```
