---
title: Two-Dimensional Scrolling
description: Independent row and column scrolling with lazy delegates.
icon: Move3d
---

[`TwoDimensionalScrollable`](/docs/api/navigation/two-dimensional) owns two independent scroll positions plus gesture
policy; [`TwoDimensionalViewport`](/docs/api/navigation/two-dimensional) owns row/column state with lazy extents.

```rust
use incular::prelude::*;

fn main() {
    let delegate =
        TwoDimensionalChildDelegate::new(10, 5, |vicinity: ChildVicinity| {
            Some(format!("{}:{}", vicinity.x_index, vicinity.y_index))
        });
    let mut scrollable = TwoDimensionalScrollable::with_new_controllers();
    scrollable.set_main_axis(Axis::Vertical);
    scrollable.set_diagonal_drag_behavior(DiagonalDragBehavior::Free);
    println!("rows: {}", delegate.row_count());
}
```

[`CacheExtentStyle`](/docs/api/navigation/two-dimensional): `Pixels` (default) / [`Viewport`](/docs/api/navigation/custom-scroll-view).
[`DiagonalDragBehavior`](/docs/api/navigation/two-dimensional): `None` (default, lock dominant) / `Free` / `Weighted`.
Layouts: [`TwoDimensionalChildLayout`](/docs/api/navigation/two-dimensional), [`TwoDimensionalViewportLayout`](/docs/api/navigation/two-dimensional)
(`child()`, ranges, cache rect), [`TwoDimensionalConstraints`](/docs/api/navigation/two-dimensional)
(`as_box_constraints()`, `constrain()`, `biggest()`).

Related: [`ScrollController`](/docs/api/navigation/scroll-controller),
[`CustomScrollView`](/docs/api/navigation/custom-scroll-view).
