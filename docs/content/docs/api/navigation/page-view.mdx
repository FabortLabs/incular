---
title: PageView
description: Snapping page carousel with viewport fraction control.
icon: GalleryHorizontal
---

`PageController = ScrollController`. Default physics: `clamping().page()` when
snapping, else `clamping()`.

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                PageView::builder(3, |i| Text::new(format!("page {i}")))
                    .page_snapping(true)
                    .viewport_fraction(1.0),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

`is_reverse()`, `is_page_snapping()`, `viewport_fraction_value()`,
`get_scroll_direction()`.
