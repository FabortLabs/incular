---
title: PageView
description: Snapping page carousel with viewport fraction control.
icon: GalleryHorizontal
---

`PageController = ScrollController`. Default physics: `clamping().page()` when
snapping, else `clamping()`.

```rust
PageView::new(pages)
    .controller(c)
    .scroll_direction(Axis::Horizontal)
    .reverse(false)
    .page_snapping(true)      // default true
    .viewport_fraction(1.0)   // clamps >= 0.01
    .physics(p)
PageView::builder(n, |i| page(i))
```

`is_reverse()`, `is_page_snapping()`, `viewport_fraction_value()`,
`get_scroll_direction()`.
