Keep the controller outside rebuilds to preserve position.

| Member | Kind | Notes |
| --- | --- | --- |
| `ScrollController::new()` | Constructor | Holds pixel position |
| `jump_to(px)` | Command | Immediate jump |
| `animate_to(px, dur, curve)` | Command | Animated scroll |
| `position()` | Query | [`ScrollMetrics`](/docs/api/navigation/scroll-controller): pixels, viewport, range |
| [`ClampingScrollPhysics`](/docs/api/navigation/scroll-controller) | Policy | Hard stop at edges |
| [`BoundaryPhysics`](/docs/api/navigation/scroll-controller) | Policy | Custom boundary behavior |
| [`SnapPhysics`](/docs/api/navigation/scroll-controller) | Policy | Snap to item/page boundaries |

## ScrollController

```rust
use incular::prelude::*;

fn main() {
    let controller = ScrollController::new();
    controller.jump_to(0.0);
    let app = Application::new(move |_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                ListView::builder(100, |i| Text::new(format!("row {i}")))
                    .controller(controller.clone())
                    .physics(ScrollPhysics::clamping()),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

`PageController = ScrollController` (see [`PageView`](/docs/api/navigation/page-view)).

## Supporting enums

[`Scrollability`](/docs/api/navigation/scroll-controller): `Enabled` / `Disabled`. [`DragStartBehavior`](/docs/api/navigation/scroll-controller): `Start` /
`Down`. [`ScrollViewKeyboardDismissBehavior`](/docs/api/navigation/scroll-controller): `Manual` / `OnDrag`.

## Metrics and notifications

[`ScrollMetrics`](/docs/api/navigation/scroll-controller) carries pixels, viewport, and range extents.
`NotificationListener::new(child)` observes scroll notifications (return `true`
to stop bubbling); `ScrollNotificationObserver::new(child)` is the
passthrough form.

[`ScrollNotificationType`](/docs/api/navigation/scroll-controller): start / update / end / overscroll variants with
metrics payloads. See [`Physics`](/docs/api/painting/physics) for spring and
friction tuning.

## ScrollView and SingleChildScrollView

```rust
use incular::prelude::*;

fn main() {
    let controller = ScrollController::new();
    let app = Application::new(move |_cx| {
        SingleChildScrollView::new(Text::new("Hi")).controller(
            controller.clone(),
        ).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

`ScrollView::vertical` is the retained-viewport helper; [`SingleChildScrollView`](/docs/api/navigation/scroll-controller)
adds direction, reversal, padding, and explicit controller/physics.

Related: [`ListView`](/docs/api/navigation/list-view),
[`SliverList`](/docs/api/navigation/sliver-list).
