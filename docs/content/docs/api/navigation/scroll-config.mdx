---
title: Scroll Configuration
description: Ambient physics and primary-controller scopes for scroll subtrees.
icon: Settings2
---

[`ScrollConfiguration`](/docs/api/navigation/scroll-config) sets ambient physics/behavior for descendant scroll
views; [`PrimaryScrollController`](/docs/api/navigation/scroll-config) associates a controller as the subtree
default.

```rust
use incular::prelude::*;

fn main() {
    let controller = ScrollController::new();
    let app = Application::new(move |_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                ScrollConfiguration::new(
                    PrimaryScrollController::new(
                        controller.clone(),
                        ListView::builder(50, |i| {
                            Text::new(format!("row {i}"))
                        }),
                    ),
                )
                .physics(ScrollPhysics::clamping()),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

[`ScrollNotificationSubscription`](/docs/api/navigation/scroll-controller) is the RAII listener handle from
`add_notification_listener` / `add_listener` (drop removes the listener).

Related: [`ScrollController`](/docs/api/navigation/scroll-controller),
[`ListView`](/docs/api/navigation/list-view).
