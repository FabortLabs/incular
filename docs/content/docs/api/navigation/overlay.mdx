Semantic owner for menus, tooltips, and popovers. The popup child is a
renderer-neutral surface partition a desktop backend may detach into a native
popup.

## Props

<TypeTable
  type={{
    child: {
      description: 'Anchor content owning the popup',
      type: <a className="underline" href="/docs/api/layout-widgets/widget">Widget</a>,

    overlay_child: {
      description: 'Popup surface; may detach natively',
      type: <>Option&lt;<a className="underline" href="/docs/api/layout-widgets/widget">Widget</a>&gt;</>,

      default: 'Popover',

    root_overlay: {
      description: 'Ignore enclosing portal',
      type: 'bool',
      default: 'false',
    },
  }}
/>

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                OverlayPortal::new(Text::new("Anchor"))
                    .overlay_child(Text::new("Popup"))
                    .show(true),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

[`TransientRole`](/docs/api/navigation/overlay) drives defaults; `for_role(Tooltip)` narrows dismissal.
[`TransientPresentation`](/docs/api/navigation/overlay): `Auto` and explicit in-view/native modes.

See [`TransientPlacement`](/docs/api/navigation/transient-placement) for
sides, alignment, flip/shift/constrain policy, and dismissal reasons.

Related: [`Navigator`](/docs/api/navigation/navigator),
[`Stack`](/docs/api/layout-widgets/stack).
