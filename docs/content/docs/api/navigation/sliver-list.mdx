---
title: SliverList
description: Lazy list sliver with fixed, varied, and prototype extents.
icon: List
---

Everything here implements the [`Sliver`](/docs/api/navigation/sliver-list) trait (`build`, `create_render_sliver`).
The retained viewport materializes only the visible range plus a bounded cache.

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        CustomScrollView::new(vec![
            Box::new(SliverList::builder(10, |i| {
                Text::new(format!("row {i}"))
            })) as Box<dyn Sliver>,
        ]).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

| Type | Extent strategy |
| --- | --- |
| [`SliverList`](/docs/api/navigation/sliver-list) | Builder rows, estimated extents |
| [`SliverFixedExtentList`](/docs/api/navigation/sliver-list) | Uniform extent, direct division math |
| [`SliverVariedExtentList`](/docs/api/navigation/sliver-list) | Per-index extent function |
| [`SliverPrototypeExtentList`](/docs/api/navigation/sliver-list) | Extents from a measured prototype |
| `SliverLayout` | Geometry + materialized children of one layout pass |

Fixed extents derive ranges by division; variable extents learn exact sizes
from laid-out children and compensate the visible anchor when rows above
change size.

Related: [`SliverGrid`](/docs/api/navigation/sliver-grid),
[`CustomScrollView`](/docs/api/navigation/custom-scroll-view),
[`ListView`](/docs/api/navigation/list-view).
