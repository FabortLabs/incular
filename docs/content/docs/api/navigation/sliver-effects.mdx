---
title: Sliver Effects
description: Decorated, opacity, offstage, and visibility sliver wrappers.
icon: WandSparkles
---

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                CustomScrollView::new(vec![
                    Box::new(SliverOpacity::new(
                        0.5,
                        SliverToBoxAdapter::new(Text::new("Half")),
                    )) as Box<dyn Sliver>,
                    Box::new(SliverVisibility::new(
                        true,
                        SliverToBoxAdapter::new(Text::new("Seen")),
                    )) as Box<dyn Sliver>,
                ]),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

Each wraps one sliver with a single retained effect, mirroring its box-widget
counterpart ([`Opacity`](/docs/api/painting/opacity),
[`IgnorePointer`](/docs/api/input/hit-test)).

| Wrapper | Effect |
| --- | --- |
| [`DecoratedSliver`](/docs/api/navigation/sliver-effects) | Background/border decoration |
| [`SliverOpacity`](/docs/api/navigation/sliver-effects) | Group opacity, clamped `0..1` |
| [`SliverOffstage`](/docs/api/navigation/sliver-effects) | Laid out but unpainted |
| [`SliverIgnorePointer`](/docs/api/navigation/sliver-effects) | Transparent to hit-testing |
| [`SliverSafeArea`](/docs/api/navigation/sliver-effects) | System-inset padding |
| [`SliverVisibility`](/docs/api/navigation/sliver-effects) | Conditional presence |

Related: [`Sliver Groups`](/docs/api/navigation/sliver-groups).
