[`CoreTransform`](/docs/api/values/transform) (re-exported `incular_core::Transform`).

```rust
CoreTransform::IDENTITY
CoreTransform::translation(Offset::new(8.0, 0.0))
CoreTransform::scale(1.5)
CoreTransform::scale_non_uniform(2.0, 1.0)
CoreTransform::rotation(0.5) // clockwise, y-down
CoreTransform::skew(0.1, 0.0)
t.then(other)                // apply other first
t.inverse()                  // Option<Self>
t.inverse_translation()
t.translation_offset() / t.is_translation() / t.magnification_bound()
t.transform_point(p) / t.inverse_transform_point(p) // Option
t.transform_rect_bbox(rect)
```

| Constructor | Produces |
| --- | --- |
| `IDENTITY` | No-op transform |
| `translation(offset)` | Shift by offset |
| `scale(s)` / `scale_non_uniform(x, y)` | Uniform / axis scaling |
| `rotation(radians)` | Clockwise, y-down |
| `skew(x, y)` | Shear factors |

| Combinator | Effect |
| --- | --- |
| `then(other)` | Apply `other` first |
| `inverse()` | Reversed transform or `None` |
| `transform_point` / `inverse_transform_point` | Map points both ways |
| `transform_rect_bbox` | Bounding box of a mapped rect |

Used by [`Container`](/docs/api/layout-widgets/container) (`transform`) and
[`Transform`](/docs/api/painting/transform-widget).

Related: [`Offset`](/docs/api/values/offset).
