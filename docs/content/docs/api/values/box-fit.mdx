---
title: BoxFit
description: Image sizing policy with every fit mode.
icon: Image
---

[`BoxFit`](/docs/api/values/box-fit) is the [`ImageFit`](/docs/api/values/box-fit) alias.

```rust
use incular::prelude::*;

fn main() {
    let fits = [
        BoxFit::Fill,
        BoxFit::Contain,
        BoxFit::Cover,
        BoxFit::FitWidth,
        BoxFit::FitHeight,
        BoxFit::None,
        BoxFit::ScaleDown,
    ];
    println!("fits: {}", fits.len());
}
```

| Variant | Layout |
| --- | --- |
| `Fill` | Stretch, ignoring aspect |
| `Contain` | Fit inside, full content visible (default) |
| `Cover` | Fill bounds, cropping overflow |
| `FitWidth` | Match width; crop an image if its fitted height would overflow |
| `FitHeight` | Match height; crop an image if its fitted width would overflow |
| `None` | Keep the natural scale; crop an image if it is too big |
| `ScaleDown` | Keep the whole image, shrinking only if it is too big |

Used by [`FittedBox`](/docs/api/layout-widgets/fitted-box) (`fit`, default
`Contain`) and [`Image`](/docs/api/content/image).

`apply_box_fit(fit, input, output)` returns the source crop size and destination
size before alignment. Image painting uses both sizes, so cropping does not
require painting outside the box. `FittedBox` transforms a child widget instead:
use its `clip_behavior` to control whether overflowing child content is visible.

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let pixels = ImageHandle::from_rgba8(2, 2, vec![255u8; 16]).expect("image");
    let app = Application::new(move |_cx| {
        Directionality::new(
            TextDirection::Ltr,
            Container::builder()
                .padding(EdgeInsets::all(24.0))
                .alignment(Alignment::CENTER)
                .child(
                    SizedBox::new()
                        .width(200.0)
                        .height(120.0)
                        .child(                Image::new(pixels.clone()).fit(BoxFit::Cover)),
                )
                .build(),
        )
        .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```
