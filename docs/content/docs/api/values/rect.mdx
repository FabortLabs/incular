---
title: Rect
description: Origin plus size with hit and intersection tests.
icon: Square
---

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let area = Rect::from_origin_size(Offset::ZERO, Size::new(200.0, 120.0));
    let hit = area.contains(Offset::new(10.0, 10.0));
    let app = Application::new(move |_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(Text::new(format!("hit: {hit}")))
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

| Member | Kind | Notes |
| --- | --- | --- |
| `from_origin_size` | Constructor | Origin + size pair |
| `origin` / `size` | Fields | Public |
| `contains` | Query | Inclusive bounds hit test |
| `intersects` | Query | Overlap check |
| `intersection` | Query | Overlapping rect or `None` |

Supports `Lerp`. Used by [`Canvas`](/docs/api/painting/canvas) clipping,
[`RRect`](/docs/api/painting/path), and
[`TransientPlacement`](/docs/api/navigation/overlay).

Related: [`Size`](/docs/api/values/size), [`Offset`](/docs/api/values/offset).
