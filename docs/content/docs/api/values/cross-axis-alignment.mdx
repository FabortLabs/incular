title: CrossAxisAlignment
description: Every cross-axis alignment variant with defaults explained.

---

```rust
use incular::prelude::*;

fn main() {
    let values = [
        CrossAxisAlignment::Start,
        CrossAxisAlignment::End,
        CrossAxisAlignment::Center,
        CrossAxisAlignment::Stretch,
        CrossAxisAlignment::Baseline,
    ];
    println!("variants: {}", values.len());
}
```

| Variant | Layout |
| --- | --- |
| `Start` | Align to the cross start (enum default) |
| `End` | Align to the cross end |
| [`Center`](/docs/api/layout-widgets/center) | Center across (flex widget default) |
| `Stretch` | Fill the cross extent |
| [`Baseline`](/docs/api/layout-widgets/baseline) | Align text baselines |

Note: the enum defaults to `Start`, but [`Row`](/docs/api/layout-widgets/row),
[`Column`](/docs/api/layout-widgets/column), and
[`Flex`](/docs/api/layout-widgets/flex) default the field to [`Center`](/docs/api/layout-widgets/center).

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Row::builder()
                    .children(Vec::<Widget>::from([
                        Text::new("Tall").into(),
                        Text::new("short").into(),
                    ]))
                    .cross_axis_alignment(CrossAxisAlignment::Center)
                    .spacing(8.0)
                    .build(),
            )
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

[`Baseline`](/docs/api/layout-widgets/baseline) pairs with the [`Baseline`](/docs/api/layout-widgets/baseline)
widget for mixed-size text rows.
