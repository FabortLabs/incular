---
title: TextDirection
description: Horizontal reading direction and vertical layout direction.
icon: ArrowLeftRight
---

```rust
use incular::prelude::*;

fn main() {
    println!("ltr: {:?}", TextDirection::Ltr);
    println!("rtl: {:?}", TextDirection::Rtl);
    println!("down: {:?}", VerticalDirection::Down);
    println!("up: {:?}", VerticalDirection::Up);
}
```

| Variant | Layout |
| --- | --- |
| `Ltr` | Left-to-right (default) |
| `Rtl` | Right-to-left; flips Row order and submenu sides |
| `Down` | Top-to-bottom (default vertical) |
| `Up` | Bottom-to-top |

Widget `text_direction` fields are `Option`, defaulting to `None` and resolving
to `Ltr`. `Rtl` flips [`Row`](/docs/api/layout-widgets/row) order and submenu
placement in [`Overlay`](/docs/api/navigation/overlay).

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Row::builder()
                    .children(Vec::<Widget>::from([
                        Text::new("First").into(),
                        Text::new("Second").into(),
                    ]))
                    .text_direction(TextDirection::Rtl)
                    .spacing(8.0)
                    .build(),
            )
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```
