---

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Flex::new(
                    Axis::Horizontal,
                    Vec::<Widget>::from([
                        Text::new("X").into(),
                        Text::new("Y").into(),
                    ]),
                ),
            )
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

| Variant | Main axis |
| --- | --- |
| `Horizontal` | x (default) |
| `Vertical` | y |

The direction in which linear layout consumes its main axis. Used by
[`Flex`](/docs/api/layout-widgets/flex), [`Wrap`](/docs/api/layout-widgets/wrap),
and scroll views.

Related: [`MainAxisAlignment`](/docs/api/values/main-axis-alignment).
