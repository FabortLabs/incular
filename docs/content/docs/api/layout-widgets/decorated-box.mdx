title: DecoratedBox

---

[`DecoratedBox`](/docs/api/layout-widgets/decorated-box) paints background/border around its child without clipping
(pair with an explicit clip widget when needed).

```rust
DecoratedBox::new(child)
    .size(Size::new(200.0, 100.0))
    .background(Brush::from(Color::WHITE))
    .border(Border::all(Color::BLACK, 1.0))
    .radius(8.0)
    .decoration(BoxDecoration::new().color(Color::WHITE).radius(8.0))
```
