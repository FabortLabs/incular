[`DecoratedBox`](/docs/api/layout-widgets/decorated-box) paints background/border around its child without clipping
(pair with an explicit clip widget when needed).

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Directionality::new(
            TextDirection::Ltr,
            Container::builder()
                .padding(EdgeInsets::all(24.0))
                .alignment(Alignment::CENTER)
                .child(
                    DecoratedBox::new(Text::new("Decorated"))
                        .background(Color::WHITE)
                        .border(Border::new(1.0, Color::BLACK))
                        .radius(8.0),
                )
                .build(),
        )
        .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

See [`Path`](/docs/api/painting/path) for [`BoxDecoration`](/docs/api/painting/path), [`BoxShape`](/docs/api/painting/path), and
shadow types.

`BoxDecoration::border_radius_geometry` accepts physical radii, directional
radii, or a combination of both. In a combination, leading and trailing
corners follow the current text direction and are then added to the physical
corners. For example:

```rust
use incular::prelude::*;

let physical = BorderRadius::circular(6.0);
let leading = BorderRadiusDirectional::horizontal(Radius::circular(4.0), Radius::ZERO);
let decoration = BoxDecoration::new()
    .border_radius_geometry(BorderRadiusGeometry::from(physical) + leading.into());
```
