---
title: Align
description: Position a child with fractional alignment and optional size factors.
icon: Crosshair
---

[`Align`](/docs/api/layout-widgets/align) positions its child with [`Alignment`](/docs/api/values/alignment) and
optionally sizes itself as `child * factor`. Factors default `None`, clamped
to `max(0.0)`.

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Align::new(Alignment::BOTTOM_RIGHT, Text::new("Corner"))
                    .width_factor(2.0)
                    .height_factor(2.0),
            )
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```
