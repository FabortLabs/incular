`ClipRSuperellipse { radius: f32, clip_behavior: Clip, child: Widget }` clips
with a rounded superellipse (squircle), lowering to [`ClipRRect`](/docs/api/layout-widgets/clip-rrect). Radius is
required and clamped to `>= 0`; default behavior `AntiAlias`.

```rust
ClipRSuperellipse::new(16.0, child)
```
