[`Stack`](/docs/api/layout-widgets/stack) overlays children in paint order. Alignment is absolute (left/right —
no text direction needed). Defaults: `alignment = TOP_LEFT`,
`fit = Loose`, `clip_behavior = HardEdge`.

## Construction

```rust
Stack::new(vec![
    Container::new().color(Color::WHITE).width(200.0).height(200.0).into(),
    Positioned::new(Text::new("Badge")).top(8.0).right(8.0).into(),
])
Stack::aligned(Alignment::CENTER, children)
Stack::builder().children(vec![a.into()]).alignment(Alignment::CENTER).fit(StackFit::Expand).build()
```

[`Clip`](/docs/api/values/clip).
