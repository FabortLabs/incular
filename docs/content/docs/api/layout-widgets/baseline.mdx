[`Baseline`](/docs/api/layout-widgets/baseline) places the child's baseline at the given vertical offset, clamped to
`max(0.0)` in both the setter and `new`.

## Props

<TypeTable
  type={{
    baseline: {
      description: 'Vertical offset of the child baseline; clamps to max(0.0)',
      type: 'f32',
      default: 'required',
    },
    child: {
      description: 'Content with a measurable baseline (usually text)',
      type: <a className="underline" href="/docs/api/layout-widgets/widget">Widget</a>,
      default: 'required',
    },
  }}
/>

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Row::builder()
                    .cross_axis_alignment(CrossAxisAlignment::Baseline)
                    .children(Vec::<Widget>::from([
                        Baseline::new(32.0, Text::new("Big")).into(),
                        Text::new("small").into(),
                    ]))
                    .build(),
            )
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

## Methods

```rust
pub fn new(baseline: f32, child: impl Into<Widget>) -> Self
```

Use with [`CrossAxisAlignment::Baseline`](/docs/api/values/cross-axis-alignment)
in flex layouts to align mixed-size text rows.
