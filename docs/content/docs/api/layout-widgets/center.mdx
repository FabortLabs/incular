---
title: Center
description: Center a child within itself with optional size factors.
icon: LocateFixed
---

[`Center`](/docs/api/layout-widgets/center) is a thin wrapper lowering to `Align::CENTER`, preserving factors.
Factors default `None`, clamped to `max(0.0)`.

## Props

<TypeTable
  type={{
    width_factor: {
      description: 'Self width as child width times factor; None shrink-wraps',
      type: 'Option<f32>',
      default: 'None',
    },
    height_factor: {
      description: 'Self height as child height times factor; None shrink-wraps',
      type: 'Option<f32>',
      default: 'None',
    },
    child: {
      description: 'Centered content',
      type: <a className="underline" href="/docs/api/layout-widgets/widget">Widget</a>,
      default: 'required',
    },
  }}
/>

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .child(Center::new(Text::new("Centered")).width_factor(2.0))
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```
