title: ClipOval
description: Elliptical raster clip.
icon: Circle
---

`ClipOval { clip_behavior: Clip, child: Widget }` clips with an elliptical
boundary inscribed in the box. Default behavior `AntiAlias`.

```rust
ClipOval::new(child)
ClipOval::new(child).clip_behavior(Clip::HardEdge)
```
