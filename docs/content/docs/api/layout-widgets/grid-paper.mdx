title: GridPaper
description: Engineering grid overlay for debug and design surfaces.
icon: Grid3x3
---

[`GridPaper`](/docs/api/layout-widgets/grid-paper) draws an engineering grid over a background, with major interval,
divisions, and subdivisions.

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Directionality::new(
            TextDirection::Ltr,
            Container::builder()
                .padding(EdgeInsets::all(24.0))
                .alignment(Alignment::CENTER)
                .child(
                    GridPaper::new()
                        .color(Color::rgba(120, 160, 240, 60))
                        .interval(100.0)
                        .child(Text::new("On graph paper")),
                )
                .build(),
        )
        .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

Defaults: interval `100.0`, divisions `2`, subdivisions `5`, and translucent
light blue. The grid paints over the optional child without intercepting its
pointer events. Primary, medium, and fine lines are 1, 0.5, and 0.25 logical
pixels wide. Use `.divisions(...)` and `.subdivisions(...)` to set the counts.

Use a finite, positive interval and nonzero division counts. An invalid
configuration or a grid requiring more than 16,384 lines leaves its child
visible without drawing a grid.

Related: [`CustomPaint`](/docs/api/painting/canvas).
