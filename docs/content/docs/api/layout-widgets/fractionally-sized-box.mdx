[`FractionallySizedBox`](/docs/api/layout-widgets/fractionally-sized-box) scales the child by factors of the parent constraints.
Both default `None` (no scaling); setters clamp to `max(0.0)`.

## Props

<TypeTable
  type={{
    width_factor: {
      description: 'Fraction of incoming max width; None disables',

    height_factor: {
      description: 'Fraction of incoming max height; None disables',
      type: 'Option<f32>',

    },
    child: {

```rust
FractionallySizedBox::new(child).width_factor(0.5).height_factor(0.5)
```
