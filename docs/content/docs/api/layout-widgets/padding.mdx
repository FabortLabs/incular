`Padding { padding, child }` — both required, no defaults.

## Props

<TypeTable
  type={{
    padding: {
      description: 'Insets applied around the child',
      type: <a className="underline" href="/docs/api/values/edge-insets">EdgeInsets</a>,
      default: 'required',
    },
    child: {
      description: 'Inset content',
      type: <a className="underline" href="/docs/api/layout-widgets/widget">Widget</a>,
      default: 'required',
    },
  }}
/>

```rust
Padding::new(EdgeInsets::all(8.0), child)
Padding::all(8.0, child)
Padding::symmetric(12.0, 6.0, child) // horizontal, vertical
Padding::zero(child)
Padding::builder().padding(insets).child(w).build()
```

