---
title: Visibility & Offstage
description: Conditional display with state, size, animation, and semantics retention.
icon: EyeOff
---

[`Visibility`](/docs/api/layout-widgets/visibility) conditionally displays its child; preservation flags imply
retention of the hidden subtree. [`Offstage`](/docs/api/layout-widgets/visibility) hides without unmounting:
measured, but no paint, hit-test, or semantics.

```rust
Visibility::new(child)
    .visible(false)
    .maintain_state(true)
    .maintain_size(true)
    .maintain_animation(true)
    .maintain_semantics(true)
    .replacement(placeholder)

Offstage::new(child)
Offstage::new(child).offstage(false)
```
