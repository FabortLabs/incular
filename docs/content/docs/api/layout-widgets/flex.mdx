[`Flex`](/docs/api/layout-widgets/flex) is [`Row`](/docs/api/layout-widgets/row) + [`Column`](/docs/api/layout-widgets/column)
with an explicit `direction: Axis` (default `Horizontal`). Same defaults for
everything else: `Start` / `Max` / [`Center`](/docs/api/layout-widgets/center) / `None→Ltr` / `Down` / `0.0`.

## Construction

A direction-switching [`Flex`](/docs/api/layout-widgets/flex) application — copy, paste, and run:

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Column::builder()
                    .main_axis_size(MainAxisSize::Min)
                    .spacing(12.0)
                    .children(Vec::<Widget>::from([
                        Flex::horizontal(Vec::<Widget>::from([
                                Text::new("A").into(),
                                Text::new("B").into(),
                            ]))
                            .spacing(8.0).into(),
                        Flex::builder()
                                .direction(Axis::Vertical)
                                .children(Vec::<Widget>::from([
                                    Text::new("One").into(),
                                    Text::new("Two").into(),
                                ]))
                                .main_axis_alignment(MainAxisAlignment::Center)
                                .cross_axis_alignment(CrossAxisAlignment::Stretch)
                                .spacing(4.0)
                                .build().into(),
                    ]))
                    .build(),
            )
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

## Methods

All [`Row`](/docs/api/layout-widgets/row)/[`Column`](/docs/api/layout-widgets/column) setters exist here too (`direction` first): `direction`,
`main_axis_alignment`, `main_axis_size`, `cross_axis_alignment`,
`text_direction`, `vertical_direction`, `spacing` — see the runnable program
above for every call in context.

Use [`Flex`](/docs/api/layout-widgets/flex) when the axis itself is dynamic (e.g. driven by orientation or a
[`Signal`](/docs/api/state/signal)); otherwise prefer the clearer
[`Row`](/docs/api/layout-widgets/row) / [`Column`](/docs/api/layout-widgets/column).

Related: [`Expanded`](/docs/api/layout-widgets/expanded),
[`Axis`](/docs/api/values/axis).
