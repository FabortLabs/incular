[`Flex`](/docs/api/layout-widgets/flex) is [`Row`](/docs/api/layout-widgets/row) + [`Column`](/docs/api/layout-widgets/column)
with an explicit `direction: Axis` (default `Horizontal`). Same defaults for
everything else: `Start` / `Max` / [`Center`](/docs/api/layout-widgets/center) / `None→Ltr` / `Down` / `0.0`.

## Construction

```rust
Flex::new(Axis::Horizontal, vec![Text::new("A").into()])
Flex::horizontal(vec![Text::new("A").into()])
Flex::vertical(vec![Text::new("A").into()])
Flex::builder().direction(Axis::Vertical).children(items).spacing(4.0).build()
```

## Methods

```rust
flex.direction(Axis::Vertical)
flex.main_axis_alignment(MainAxisAlignment::Center)
flex.main_axis_size(MainAxisSize::Min)
flex.cross_axis_alignment(CrossAxisAlignment::Stretch)
flex.text_direction(TextDirection::Rtl)
flex.vertical_direction(VerticalDirection::Up)
flex.spacing(4.0)
```

Use [`Flex`](/docs/api/layout-widgets/flex) when the axis itself is dynamic (e.g. driven by orientation or a
[`Signal`](/docs/api/state/signal)); otherwise prefer the clearer
[`Row`](/docs/api/layout-widgets/row) / [`Column`](/docs/api/layout-widgets/column).

Related: [`Expanded`](/docs/api/layout-widgets/expanded),
[`Axis`](/docs/api/values/axis).
