---
title: RotatedBox
description: Quarter-turn rotation about the child center.
icon: RotateCw
---

`RotatedBox { quarter_turns: i32, child: Widget }` rotates by integral
quarter-turns (layout swaps axes for odd counts).

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(RotatedBox::new(1, Text::new("Sideways")))
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

For arbitrary angles use [`Transform`](/docs/api/painting/transform-widget)
rotation instead.

Related: [`Transform`](/docs/api/painting/transform-widget).
