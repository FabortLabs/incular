title: Wrap
description: Flowing multi-run layout with per-run and cross-run alignment.

---

[`Wrap`](/docs/api/layout-widgets/wrap) places children sequentially, wrapping onto new runs past the main-axis
extent. Defaults: `direction = Horizontal`, `alignment = Start`,
`spacing = 0.0`, `run_alignment = Start`, `run_spacing = 0.0`,
`cross_axis_alignment = Start`, `text_direction = None` (`Ltr`),
`vertical_direction = Down`.

## Construction

A tag cloud — copy, paste, and run:

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Wrap::new(Vec::<Widget>::from([
                    Text::new("rust").into(),
                    Text::new("gui").into(),
                    Text::new("native").into(),
                    Text::new("retained").into(),
                ]))
                .direction(Axis::Horizontal)
                .alignment(WrapAlignment::Start)
                .spacing(8.0)
                .run_alignment(WrapAlignment::Start)
                .run_spacing(8.0)
                .cross_axis_alignment(WrapCrossAlignment::Start)
                .text_direction(TextDirection::Ltr)
                .vertical_direction(VerticalDirection::Down),
            )
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

[`WrapAlignment`](/docs/api/values/wrap-alignment): `Start` / `End` / [`Center`](/docs/api/layout-widgets/center) / `SpaceBetween` / `SpaceAround` /
`SpaceEvenly` (both within a run and across runs). [`WrapCrossAlignment`](/docs/api/values/wrap-alignment):
`Start` / `End` / [`Center`](/docs/api/layout-widgets/center). See
[`WrapAlignment`](/docs/api/values/wrap-alignment).

```rust
use incular::prelude::*;

fn main() {
    let app = Application::new(|_cx| {
        Wrap::new(Vec::<Widget>::from([
                Text::new("rust").into(),
                Text::new("gui").into(),
            ]))
            .spacing(6.0)
            .run_spacing(6.0).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```
