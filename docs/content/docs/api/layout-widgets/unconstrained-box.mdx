---
title: UnconstrainedBox
description: Natural child sizing plus constraint-transforming boxes.
icon: Maximize
---

[`UnconstrainedBox`](/docs/api/layout-widgets/unconstrained-box) lets its child size naturally without parent constraints,
optionally keeping one axis constrained.

```rust
UnconstrainedBox::new(child)
UnconstrainedBox::new(child).constrained_axis(Axis::Horizontal)
```

[`ConstraintsTransformBox`](/docs/api/layout-widgets/unconstrained-box) maps incoming [`Constraints`](/docs/api/values/constraints)
through a function before measuring the child.

```rust
ConstraintsTransformBox::new(|c| c.loosen(), child)
    .alignment(Alignment::CENTER)
    .clip_behavior(Clip::None)
```

Related: [`ConstrainedBox`](/docs/api/layout-widgets/constrained-box),
[`OverflowBox`](/docs/api/layout-widgets/overflow-box).
