`SizedBox { width, height, child }` — all `None` by default (unconstrained
passthrough). Prefer it over [`Container`](/docs/api/layout-widgets/container)
for pure spacers.

## Props

<TypeTable

## Construction

```rust
SizedBox::new().width(10.0).height(20.0).child(w)
SizedBox::square(48.0)
SizedBox::from_size(Size::new(100.0, 40.0))
SizedBox::from_dimensions(Some(100.0), Some(40.0), Some(w))
SizedBox::shrink() // 0x0
SizedBox::expand() // infinity x infinity
SizedBox::empty()
SizedBox::builder().width(10.0).height(20.0).child(w).build()
```
