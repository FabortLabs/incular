[`IndexedStack`](/docs/api/layout-widgets/indexed-stack) lays out every child but paints only the selected index —
state-preserving tab bodies. Defaults: `index = 0`,
`alignment = TOP_LEFT`, `fit = Loose`, `clip_behavior = HardEdge`.

## Construction

Signal-driven tabs — copy, paste, and run:

```rust
use incular::prelude::*;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let tab = Signal::new(0usize);
    let current = tab.clone();
    let app = Application::new(move |_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                IndexedStack::new(Vec::<Widget>::from([
                    Text::new("Home page").into(),
                    Text::new("Search page").into(),
                    Text::new("Settings page").into(),
                ]))
                .index(current.get())
                .alignment(Alignment::CENTER),
            )
            .build()
            .into()
    })?;
    incular::run(app)?;
    Ok(())
}
```

`IndexedStack::new(pages).index(1).alignment(Alignment::CENTER).fit(StackFit::Expand)`
shows the same calls without a signal.
