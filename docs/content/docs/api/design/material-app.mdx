| Shell | Purpose |
| --- | --- |
| [`MaterialApp`](/docs/api/design/material-app) | Theme, routes, locale, restoration root |
| [`Scaffold`](/docs/api/design/material-app) | Body + bars + drawers + sheets page frame |
| [`AppBar`](/docs/api/design/material-app) / [`SliverAppBar`](/docs/api/navigation/sliver-headers) / [`BottomAppBar`](/docs/api/design/material-app) | Top, collapsing, and bottom bars |
| [`Drawer`](/docs/api/design/material-app) / [`NavigationRail`](/docs/api/design/material-app) / [`NavigationDrawer`](/docs/api/design/material-app) | Side navigation patterns |
| [`ScaffoldMessenger`](/docs/api/design/material-app) | Snack bar queue owner |

```rust
use incular::prelude::*;
use incular::material_prelude::{AppBar, MaterialApp, Scaffold, ThemeData};

fn main() {
    let app = Application::new(|_cx| {
        MaterialApp::new(
            Scaffold::new(Text::new("Body"))
                .app_bar(AppBar::new(Text::new("Demo"))),
        )
        .title("Demo")
        .theme(ThemeData::light())
        .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

`route` / `routes` / `initial_route`, locale and supported locales,
`restoration_scope_id`, `builder`, `from_builder`, drawer/navigation-bar
slots, [`ScaffoldMessenger`](/docs/api/design/material-app), and action buttons ([`BackButton`](/docs/api/design/material-app), [`CloseButton`](/docs/api/design/material-app),
[`DrawerButton`](/docs/api/design/material-app)) share the same consuming-builder shape.

`K_TOOLBAR_HEIGHT = 56.0`. [`ThemeMode`](/docs/api/design/theme): `System` / `Light` / `Dark`.
