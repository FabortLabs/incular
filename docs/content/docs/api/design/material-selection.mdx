| Control | Value |
| --- | --- |
| [`Checkbox`](/docs/api/design/selection) | `bool` + tristate `Option<bool>` |
| `Radio<T>` / `RadioGroup<T>` | Shared group selection |
| [`Switch`](/docs/api/design/selection) | `bool` toggle |
| [`Slider`](/docs/api/design/material-selection) | `f32` in range with divisions |
| [`RangeSlider`](/docs/api/design/material-selection) | [`RangeValues`](/docs/api/design/material-selection) start/end pair |

```rust
use incular::prelude::*;
use incular::material_prelude::{Checkbox, Slider};

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Column::builder()
                    .main_axis_size(MainAxisSize::Min)
                    .spacing(8.0)
                    .children(Vec::<Widget>::from([
                        Checkbox::new(false)
                                .on_changed(|v| println!("checked: {v:?}")).into(),
                        Slider::new(0.5)
                                .range(0.0, 1.0)
                                .on_changed(|v| println!("slider: {v}")).into(),
                    ]))
                    .build(),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

[`Switch`](/docs/api/design/selection), [`Radio`](/docs/api/design/selection), [`RangeSlider`](/docs/api/design/material-selection), and the [`SliderInteraction`](/docs/api/design/material-selection) / [`SliderThemeData`](/docs/api/design/material-selection)
options share the same consuming-builder shape.

[`SliderInteraction`](/docs/api/design/material-selection): `TapAndSlide` (default) / `TapOnly` / `SlideOnly` /
`SlideThumb`. [`SliderThemeData`](/docs/api/design/material-selection) (all `Option`): track height, thumb size,
track/thumb/overlay/tick colors, value indicator, padding, constraints.

Related: [`Selection`](/docs/api/design/selection).
