---
title: Scrollbar
description: Themed retained scrollbar wrapping a scroll viewport.
icon: MoveVertical
---

```rust
use incular::prelude::*;
use incular::controls_prelude::Scrollbar;

fn main() {
    let controller = ScrollController::new();
    let app = Application::new(move |_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Scrollbar::new(
                    ListView::builder(100, |i| Text::new(format!("row {i}"))),
                )
                .controller(controller.clone())
                .thumb_visibility(true),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

| Prop | Type | Default |
| --- | --- | --- |
| `controller` | [`ScrollController`](/docs/api/navigation/scroll-controller) | Viewport's own |
| `style` | [`RawScrollbarStyle`](/docs/api/design/scrollbar) | Theme-derived |
| `thumb_visibility` | `bool` | `false` (hover-reveal) |

Reuses the existing [`SingleChildScrollView`](/docs/api/navigation/scroll-controller) controller when present.
Theme-derived style: `theme.scrollbar.width` (8), `min_thumb_extent` (24),
transparent track, `foreground_muted` thumb.

[`RawScrollbar`](/docs/api/design/scrollbar) is the stateful overlay (`geometry()`, `pointer_down/move/up`,
`hit_test()`); `RawScrollbarGeometry { visible, track, thumb, … }` carries
computed geometry; [`RawScrollbarOrientation`](/docs/api/design/scrollbar): `Right` (default) / `Left` /
`Bottom` / `Top`.

Related: [`ScrollController`](/docs/api/navigation/scroll-controller).
