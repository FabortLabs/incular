```rust
use incular::material_prelude::MenuController;

fn main() {
    let controller = MenuController::new();
    controller.open();
    println!("open: {}", controller.is_open());
    controller.close();
}
```

[`MenuStyle`](/docs/api/design/material-menus) (sparse): background/shadow/tint colors, elevation, padding,
sizes, side, shape, alignment. [`PopupMenuPosition`](/docs/api/design/material-menus): `Over` (default) /
`Under`. [`DropdownMenuCloseBehavior`](/docs/api/design/material-menus): `All` (default) / `SelfOnly` / `None`.

## Keyboard accelerators and shortcut labels

`MenuAcceleratorLabel::new("&File")` underlines the letter after `&` while
Alt is held and activates the item when that letter is pressed, as Flutter's
does. `&&` is a literal ampersand. `MenuAcceleratorLabel::strip_accelerator_markers`
returns the plain label and the accelerator's index. Menu items publish
their activation through `MenuAcceleratorCallbackBinding`.

`MenuItemButton::shortcut(activator)` shows the shortcut's label in the
platform's style: `Ctrl+S` on Windows and Linux, and modifier symbols such as `⌘` on Apple platforms.
`shortcut_label(&activator, platform)` and `character_shortcut_label` produce
the same text. The label is display only: register the shortcut itself, for
example with a [`ShortcutRegistry`](/docs/api/input/keyboard#shortcutregistry).

`CheckboxMenuButton::new(value, child)` is a tristate-capable checkbox item,
and `RadioMenuButton::new(value, group_value, child)` is a radio item. Both
take `on_changed`, `shortcut`, `trailing_icon` and `close_on_activate`.

```text
MenuBar::new(vec![
    SubmenuButton::new(MenuAcceleratorLabel::new("&File"), vec![
        MenuItemButton::new(MenuAcceleratorLabel::new("&Save"))
            .shortcut(SingleActivator::new(KeyboardKey::character("s"), Modifiers::CONTROL)),
        CheckboxMenuButton::new(Some(true), Text::new("Autosave")).on_changed(|v| {}),
    ]),
])
```
