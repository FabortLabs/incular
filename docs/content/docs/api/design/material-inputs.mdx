| Input | Purpose |
| --- | --- |
| [`TextField`](/docs/api/design/text-inputs) | Material-styled controller editor |
| [`TextFormField`](/docs/api/design/material-inputs) | Field with validator + form registration |
| [`SelectableText`](/docs/api/design/material-inputs) / [`SelectionArea`](/docs/api/design/material-inputs) | Read-only selectable runs |
| [`InputDecoration`](/docs/api/design/material-inputs) | Label, hint, helper, and error chrome |

```rust
use incular::prelude::*;
use incular::material_prelude::{SelectableText, TextField};

fn main() {
    let app = Application::new(|_cx| {
        Container::builder()
            .padding(EdgeInsets::all(24.0))
            .alignment(Alignment::CENTER)
            .child(
                Column::builder()
                    .main_axis_size(MainAxisSize::Min)
                    .spacing(8.0)
                    .children(Vec::<Widget>::from([
                        TextField::new(
                                TextEditingController::with_text(""),
                            )
                            .placeholder("Name").into(),
                        SelectableText::new("Copy me").into(),
                    ]))
                    .build(),
            )
            .build()
            .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

[`TextFormField`](/docs/api/design/material-inputs) adds validators and form registration; [`SelectionArea`](/docs/api/design/material-inputs)
scopes selection; [`InputDecoration`](/docs/api/design/material-inputs) provides label/hint/helper/error chrome.

Related: [`TextField`](/docs/api/design/text-inputs),
[`EditableText`](/docs/api/content/editable-text),
[`Form`](/docs/api/input/form).
