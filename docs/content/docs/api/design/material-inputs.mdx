| Input | Purpose |
| --- | --- |
| [`TextField`](/docs/api/design/text-inputs) | Material-styled controller editor |
| [`TextFormField`](/docs/api/design/material-inputs) | Field with validator + form registration |
| [`SelectableText`](/docs/api/design/material-inputs) / [`SelectionArea`](/docs/api/design/material-inputs) | Read-only selectable runs |
| [`InputDecoration`](/docs/api/design/material-inputs) | Label, hint, helper, and error chrome |

```rust
TextField::new(controller)
    .placeholder("Name")
    .decoration(InputDecoration::new().label("Name").hint("John"))
    .style(TextStyle::new()).max_lines(Some(1)).multiline(false)
    .on_submit(|v| {}).on_changed(|v| {})
    .enabled(true).read_only(false).obscure_text(false)
    .max_length(Some(140)).autofocus(false)
TextFormField::new()
    .validator(|v| if v.is_empty() { Some("Required".into()) } else { None })
    .register_with_form(&form)
    .decoration(InputDecoration::new())
SelectableText::new("Copy me")
SelectionArea::new(child)
InputDecoration::new().label("Name").hint("John").helper("...").error("!")
```
