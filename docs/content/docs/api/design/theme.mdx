## ControlTheme

```rust
use incular::prelude::*;
use incular::controls_prelude::{ControlDensity, ControlTheme, ControlThemeScope};

fn main() {
    let theme = ControlTheme::dark().density(ControlDensity::Compact);
    let app = Application::new(move |_cx| {
        ControlThemeScope::new(theme.clone(), Text::new("Hi")).into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

[`ControlDensity`](/docs/api/design/theme): `Compact` (26 px) / `Standard` (default, 32 px) /
`Comfortable` (38 px).

## ControlState

`u16` bitset flags: `DISABLED`, `HOVERED`, `PRESSED`, `FOCUSED`, `CHECKED`,
`SELECTED`, `EXPANDED`, `INVALID`, `READ_ONLY`, `DRAGGING`, `OPEN`,
`FOCUS_VISIBLE`.

```rust
use incular::controls_prelude::ControlState;

fn main() {
    let state = ControlState::empty().with(ControlState::CHECKED);
    println!("pressed: {}", state.contains(ControlState::PRESSED));
    println!("checked: {}", state.contains(ControlState::CHECKED));
    println!("enabled: {:?}", ControlState::from_enabled(true));
}
```

`StateValue<T>`: `Value(T)` / `States(StateTable<T>)` /
`Resolver(fn)`. [`StateColor`](/docs/api/design/button): compact normal/hover/pressed/focused/disabled/
checked/selected set. Resolution precedence: disabled → invalid → pressed →
checked → focused → hovered → normal. See [`Button`](/docs/api/design/button).

## Colors, typography, metrics, motion

```rust
use incular::prelude::*;
use incular::controls_prelude::{
    ControlColors, ControlMetrics, ControlMotion, ControlTypography,
};

fn main() {
    let colors = ControlColors::dark();
    println!("accent set: {}", colors.accent != Color::TRANSPARENT);
    let type_ = ControlTypography::new(Color::WHITE, Color::WHITE);
    println!("has body: {}", type_.body.size > 0.0);
    println!("metrics: {}", ControlMetrics::default().control_height);
    println!("motion: {}", ControlMotion::default().hover_duration_ms);
}
```

Token sets: [`SpacingTokens`](/docs/api/design/theme) (xs 4 → xl 24), [`RadiusTokens`](/docs/api/design/theme) (0/3/5/8/999),
[`ElevationTokens`](/docs/api/design/theme) (0/8/24). Per-component themes: [`ButtonTheme`](/docs/api/design/theme), [`InputTheme`](/docs/api/design/theme),
[`CheckboxTheme`](/docs/api/design/theme), [`RadioTheme`](/docs/api/design/theme), [`SwitchTheme`](/docs/api/design/theme), [`PopupTheme`](/docs/api/design/theme), [`ScrollbarTheme`](/docs/api/design/theme),
[`SliderTheme`](/docs/api/design/theme), [`MenuTheme`](/docs/api/design/theme), [`TooltipTheme`](/docs/api/design/theme), [`TabsTheme`](/docs/api/design/theme), [`ProgressTheme`](/docs/api/design/theme),
[`AvatarTheme`](/docs/api/design/theme), [`ToastTheme`](/docs/api/design/theme).

## Button styling

[`ButtonStyle`](/docs/api/design/button) sparse config with [`StateValue`](/docs/api/design/button)/[`StateColor`](/docs/api/design/button) resolution
(disabled → invalid → pressed → checked → focused → hovered → normal):

```rust
use incular::prelude::*;
use incular::controls_prelude::{ButtonStyle, ButtonVariant};

fn main() {
    let style = ButtonStyle::new()
        .variant(ButtonVariant::Primary)
        .elevation(1.0)
        .border_radius(6.0)
        .minimum_size(Size::new(64.0, 36.0));
    println!("tap target: {:?}", style.tap_target_size);
}
```

[`ControlState`](/docs/api/design/theme) flags: `DISABLED`, `HOVERED`, `PRESSED`, `FOCUSED`, `CHECKED`,
`SELECTED`, `EXPANDED`, `INVALID`, `READ_ONLY`, `DRAGGING`, `OPEN`,
`FOCUS_VISIBLE`.

## Material ThemeData

[`Brightness`](/docs/api/design/theme): `Light` (default) / `Dark` — platform color preference driving
`ThemeMode::System` resolution.

```rust
use incular::prelude::*;
use incular::controls_prelude::{ControlTheme, ControlThemeScope};

fn main() {
    let app = Application::new(|_cx| {
        ControlThemeScope::new(
            ControlTheme::dark(),
            Container::builder()
                .padding(EdgeInsets::all(24.0))
                .alignment(Alignment::CENTER)
                .child(Text::new("Themed"))
                .build(),
        )
        .into()
    })
    .expect("valid application");
    incular::run(app).expect("run application");
}
```

```rust
use incular::material_prelude::{ThemeData, ThemeMode};

fn main() {
    let _light = ThemeData::light();
    let _dark = ThemeData::dark();
    println!("mode: {:?}", ThemeMode::System);
    println!("themes built");
}
```
