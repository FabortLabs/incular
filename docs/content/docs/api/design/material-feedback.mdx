---
title: Material Feedback
description: Dialogs, snack bars, tooltips, and progress indicators.
icon: MessageSquare
---

```rust
AlertDialog::new().title(Text::new("Delete?")).content(Text::new("Sure?"))
    .actions(vec![cancel.into(), ok.into()]).scrollable(true)
SimpleDialog::new().title(Text::new("Pick")).children(options)
SimpleDialogOption::new(Text::new("A")).on_pressed(|| {})
Dialog::new(child).inset_padding(p).shape(s)
show_dialog(dialog) // DialogHandle: open/close/dismiss/barrier_dismissible
SnackBar::text("Saved").action(SnackBarAction::new("Undo", || {}))
    .behavior(SnackBarBehavior::Floating).duration(Duration::from_secs(4))
Tooltip::new("Save", child).trigger_mode(TooltipTriggerMode::Hover)
    .wait_duration(Duration::from_millis(500))
LinearProgressIndicator::new().value(Some(0.4)) // None = indeterminate
CircularProgressIndicator::new().size(24.0).stroke_width(4.0)
```

| Type | Purpose |
| --- | --- |
| [`AlertDialog`](/docs/api/design/material-feedback) | Title + content + action row |
| [`SimpleDialog`](/docs/api/design/material-feedback) / [`SimpleDialogOption`](/docs/api/design/material-feedback) | Option list dialog |
| [`Dialog`](/docs/api/navigation/navigator) | Bare dialog shell with insets and shape |
| [`DialogHandle`](/docs/api/design/material-feedback) | `open` / `close` / `dismiss`, barrier control |
| [`SnackBar`](/docs/api/design/material-feedback) + [`SnackBarAction`](/docs/api/design/material-feedback) | Timed message with optional action |
| [`Tooltip`](/docs/api/design/material-feedback) | Hover/focus/tap hint with delays |
| [`LinearProgressIndicator`](/docs/api/design/material-feedback) / [`CircularProgressIndicator`](/docs/api/design/material-feedback) | Determinate or indeterminate progress |

[`SnackBarBehavior`](/docs/api/design/material-feedback): `Fixed` (default) / `Floating`. [`TooltipTriggerMode`](/docs/api/design/material-feedback):
`Hover` (default) / [`Focus`](/docs/api/input/focus) / `Tap` / `Manual`.
[`ProgressIndicatorStrokeCap`](/docs/api/design/material-feedback): `Butt` (default) / `Round` / `Square`.
